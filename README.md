# H&J Health

Aplicativo web pessoal para acompanhar alimentação, água, suplementos, treino, sono, medições, exames e consultas.

- HTML, CSS e JavaScript puros, sem dependências e sem chamadas externas.
- Funciona offline após o primeiro acesso (service worker).
- **Este repositório não contém dados de saúde.** Os dados entram por importação de arquivo em cada aparelho e ficam só no armazenamento local daquele aparelho (IndexedDB).

Ao publicar uma nova versão, altere `VERSAO` em `sw.js`.
